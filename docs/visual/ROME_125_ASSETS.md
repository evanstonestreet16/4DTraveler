# Rome / 125 CE overview assets

The runtime uses three checked-in WebP images under `public/images/rome-125/`:

- `overview.webp`: 1586 × 992 desktop view;
- `overview-mobile.webp`: 954 × 1649 portrait composition;
- `overview-fallback.webp`: 1279 × 800 recovery image.

`overview.json` records content-hashed URLs, dimensions, and authored coordinates for the Forum of Trajan, Pantheon forecourt, and Flavian Amphitheatre valley markers. The artwork is an illustrative reconstruction rather than a surveyed city model.

This release does not include ground-level POI visuals.
