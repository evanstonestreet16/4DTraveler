# 360° Street View Explorer

An interactive street-view style panorama viewer built with **React 18**, **Three.js** and **Vite**. Equirectangular panoramas are looked up on disk by city and GPS coordinate, neighbouring locations are turned into compass bearings with geodesic math, and clickable ground chevrons let you walk between them.

## Features

- **Coordinate-addressed panoramas** – images live at `public/images/citystreetviews/{city}/{lat},{lon}.jpg`; the manifest in `src/data/cityManifest.js` is the only registry you need to edit.
- **Geodesic navigation** – forward-azimuth bearings and Haversine distances between the current node and every other node in the same city drive the placement and orientation of 3D ground arrows.
- **3D informational hotspots** – each arrow carries a floating label with the destination title, distance and compass direction; hovering highlights it, clicking moves you there and turns the camera toward the direction of travel.
- **Controls** – drag (mouse or touch) to look around, scroll wheel or pinch to zoom (FOV 30°–100°), arrow keys / `+` / `-` on the keyboard, fullscreen toggle.
- **HUD** – live compass (click to snap back to north), GPS badge, zoom controls, collapsible location panel listing connected panoramas, city picker in the header.
- **States** – loading blur/spinner, missing-image error with retry, and an empty state for cities without panoramas.

## Getting started

```bash
npm install
npm run dev
```

The dev server binds to <http://127.0.0.1:43617>. Other scripts:

| Script                       | Purpose                                                |
| ---------------------------- | ------------------------------------------------------ |
| `npm run build`              | Production build to `dist/`                            |
| `npm run preview`            | Serve the production build on port 43618               |
| `npm run generate:panoramas` | Create placeholder panoramas for any manifest node lacking an image (`-- --force` to overwrite) |

## Adding panoramas

1. Export an **equirectangular** JPEG (2:1 aspect, e.g. 4096×2048). The horizontal centre column of the image should face true north; the app rotates the sphere so that column lines up with heading 0°.
2. Save it as `public/images/citystreetviews/{city}/{lat},{lon}.jpg` with both coordinates written to **7 decimal places** (e.g. `41.8915000,12.4912000.jpg`). `formatCoord()` in the manifest applies the same formatting when building URLs.
3. Register the node in `src/data/cityManifest.js`:

```js
export const CITY_MANIFEST = {
  rome: [
    { lat: 41.8912948, lon: 12.4910401, title: 'Colosseum Exterior - South-West', description: '…' },
    // …
  ],
  paris: [
    { lat: 48.8583701, lon: 2.2944813, title: 'Eiffel Tower – Champ de Mars' }
  ]
};
```

New cities appear automatically in the header dropdown (add a friendly label to `CITY_LABELS` if you like). Every node in a city is treated as connected to every other node.

The three Rome images shipped in this repo are **synthetic placeholders** generated by `scripts/generate-panoramas.mjs`. They paint N/E/S/W markers at the correct columns so you can verify compass and arrow alignment; replace them with real photography when available.

## Component API

```jsx
<StreetViewViewer
  city="rome"              // key into CITY_MANIFEST (default: 'rome')
  initialLat={41.8915}     // optional; falls back to the city's first node
  initialLon={12.4912}
  onLocationChange={({ lat, lon }) => …}
/>
```

## How the geometry fits together

- The camera sits at the origin inside a 500-unit sphere with inverted normals. Heading 0° looks down −Z; heading 90° looks down +X.
- `bearingTo3DPosition()` maps a compass bearing onto that same frame (`x = r·sin θ`, `z = −r·cos θ`), so arrows and the camera share one notion of north.
- Each arrow is a textured plane laid flat (`rotation.x = −90°`) and spun around its normal by `−bearing`, so the chevron points along the direction of travel. Labels are `THREE.Sprite`s that always face the camera.
- Clicks are resolved with a `Raycaster`; a drag longer than 6 px suppresses the click so panning never triggers navigation.
