# 4DTraveler

4DTraveler is an interactive historical-world explorer: choose a place and era, enter a browser-based 3D reconstruction, visit points of interest, inspect historically significant objects, and hear contextual narration.

This repository currently contains the planning documents for the project. Implementation has intentionally not started yet.

## Project documents

- [Project overview](PROJECT_OVERVIEW.md) — product concept, experience, priorities, and technical direction.
- [Dummy v0 specification](DUMMY_V0_SPEC.md) — the planned smallest end-to-end implementation and its acceptance criteria.

## Planned first milestone

Dummy v0 will focus on a single experience: Pittsburgh in 1892. It is intended to validate the React/TypeScript and React Three Fiber structure, static world-data contract, camera transitions, POI and object selection, information panel, and local narration playback.

## Status

Documentation initialized. Dummy v0 has not been executed or implemented.
