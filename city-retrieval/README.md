# City RAG Service (MongoDB Atlas + xAI Grok + FastAPI)

A Retrieval-Augmented Generation (RAG) backend powered by **MongoDB Atlas Vector Search** for context retrieval, **OpenAI** for query embeddings, **xAI (Grok-4.3)** for text generation, and **FastAPI** to serve HTTP endpoints to web clients (e.g., React).

## 🛠 Prerequisites & Setup

### 1. Python Environment Setup

Ensure you have Python 3.10+ installed and activated in your virtual environment.

```
# Install required Python packages
pip install fastapi uvicorn pymongo openai python-dotenv

```

### 2. Configure Environment Variables (`.env`)

Create a `.env` file in the root directory of your project:

```
OPENAI_API_KEY=sk-proj-your-openai-key-here
XAI_API_KEY=xai-your-xai-api-key-here
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/?retryWrites=true&w=majority
MONGODB_DATABASE=city_rag
MONGODB_COLLECTION=city_chunks

```

This is only if you want to use your own server/API keys, otherwise ask Richard for the .env file containing the API keys

## 🚀 Running the FastAPI Server

### Step 1: Start the Backend Server

Run the `app.py` script to launch the server locally using Uvicorn:

```
python app.py

```

The server will start at: `http://127.0.0.1:8000`

### Step 2: Quickly Test the Server (No Frontend Needed)

FastAPI automatically generates an interactive API playground:

1. Open your browser and navigate to: **`http://127.0.0.1:8000/docs`**

2. Click on the **`POST /api/chat`** section.

3. Click **Try it out**.

4. Enter your query in the Request Body:

   ```
   {
     "query": "What are the top things to do in Toronto?"
   }

   ```

5. Click **Execute** to view the response generated by Grok.

Alternatively, test directly via PowerShell:

```
Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/chat" `
  -Method Post `
  -ContentType "application/json" `
  -Body '{"query": "What to do in Montreal?"}'

```

## 💻 Calling the API from React

### 1. React Component Example (`CityGuide.jsx`)

Here is a ready-to-use React component using standard `fetch` with state management for input, output, and loading state:

```
import React, { useState } from 'react';

export default function CityGuide() {
  const [query, setQuery] = useState('');
  const [answer, setAnswer] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const handleSubmit = async (e) => {
    e.preventDefault();
    if (!query.trim()) return;

    setLoading(true);
    setAnswer('');
    setError(null);

    try {
      const res = await fetch('http://127.0.0.1:8000/api/chat', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({ query }),
      });

      if (!res.ok) {
        throw new Error(`Server error: ${res.statusText}`);
      }

      const data = await res.json();
      setAnswer(data.answer);
    } catch (err) {
      setError(err.message || 'Failed to connect to backend.');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div style={{ maxWidth: '600px', margin: '40px auto', fontFamily: 'sans-serif' }}>
      <h2>City Travel Guide (Grok RAG)</h2>

      <form onSubmit={handleSubmit} style={{ display: 'flex', gap: '8px' }}>
        <input
          type="text"
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          placeholder="Ask a question (e.g. What should I visit in Toronto?)"
          style={{ flex: 1, padding: '10px', fontSize: '16px' }}
        />
        <button
          type="submit"
          disabled={loading}
          style={{ padding: '10px 20px', cursor: 'pointer' }}
        >
          {loading ? 'Searching...' : 'Ask'}
        </button>
      </form>

      {error && (
        <div style={{ color: 'red', marginTop: '16px' }}>
          <strong>Error:</strong> {error}
        </div>
      )}

      {answer && (
        <div style={{ marginTop: '24px', padding: '16px', background: '#f4f4f4', borderRadius: '8px' }}>
          <h3>Answer:</h3>
          <p style={{ lineHeight: '1.5' }}>{answer}</p>
        </div>
      )}
    </div>
  );
}

```

### 2. Axios Alternative Example

If your React project uses `axios`:

```
import axios from 'axios';

const fetchAnswer = async (userQuery) => {
  try {
    const response = await axios.post('http://127.0.0.1:8000/api/chat', {
      query: userQuery,
    });
    console.log("Grok Answer:", response.data.answer);
    return response.data.answer;
  } catch (error) {
    console.error("API Error:", error);
  }
};

```

## 📡 API Endpoint Reference

### `POST /api/chat`

- **Request Headers:** `Content-Type: application/json`

- **Request Body:**

  ```
  {
    "query": "string"
  }

  ```

- **Response Body (`200 OK`):**

  ```
  {
    "answer": "string"
  }

  ```
